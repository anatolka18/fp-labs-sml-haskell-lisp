# Репозиторий учебных работ по функциональному программированию

Данный репозиторий содержит решения лабораторных работ и отдельных задач по курсу функционального программирования.  
Используемые языки: **Standard ML (SML)**, **Haskell**, **Common Lisp**.

## Структура

- `sml/` — лабораторные работы на SML:
  - `lab_0/` — простейшие функции (double, quadruple, sixTimes)
  - `lab_1/` — работа с датами (календари, китайский гороскоп, новолуния)
  - `lab_2/` — интерпретатор языка MUPL (замыкания, окружения)
  - `lab_3/` — реализация карточной игры UNO
  - `tasks/` — отдельные небольшие задачи 
- `haskell/` — лабораторные работы на Haskell:
  - `lab_4/` — бесконечные списки, потоки, численные методы (производные, метод Ньютона, π)
  - `tasks/` — дополнительные задачи 
- `lisp/` — задачи на Common Lisp:
  - `tasks/` — работа со списками, потоками, арифметическими выражениями
- `.vscode/` — настройки редактора для быстрого запуска REPL (горячие клавиши F8, F9)

## Требования

Для запуска кода необходимо установить интерпретаторы или компиляторы для соответствующих языков:
- **SML** — например, SML/NJ или MLton
- **Haskell** — например, GHC или Hugs
- **Common Lisp** — например, SBCL 

## Настройка VS Code (опционально)
Если вы используете VS Code с расширением Millet (для SML) или стандартными расширениями для Haskell/Lisp, вы можете пользоваться горячими клавишами из .vscode/keybindings.json:

- F8 — открыть REPL для текущего языка
- F9 — загрузить текущий файл в REPL
